谈天说地 · Topic Atlas

Three map directions. Original vector studies, awaiting your choice.

A · Diorama archipelago

Raised islands with miniature landmarks. Closest to the game-world direction in the handoff. The central self island anchors the journey, while school and community have recognisable buildings. This vector sketch tests the composition before any final raster art is commissioned.

Final raster target: 220–350 KB per theme, only the active theme loaded. Current prototype uses original SVG.

B · Illustrated atlas

A flat illustrated sea chart with inked shores, paths and generous labels. It keeps the world playful while giving the clearest hotspots and simplest light/dark treatment on older iPads. My recommendation for the first release.

Final SVG target: 30–65 KB uncompressed, no raster download. Theme colours come from CSS tokens.

C · Connected learning park

One shared landmass with six districts connected by walking paths. This emphasises moving outward from self to the wider world and could later support a small avatar. This proposal is a click-to-explore map; avatar controls would be a separate decision.

Final SVG target: 45–85 KB uncompressed, no raster download. No game engine or animation required.
