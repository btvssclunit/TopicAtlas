## 2. G2 实用文：回复电邮《中学迎新活动》（教师材料）

**Why add it:** the current G2 task in `s1u1.json` is an open email to a friend. The teacher task below is in the exam format (read an email, then reply), with a writing frame the department already uses.

**Proposal:** add as a second G2 实用文 practice, or replace the current G2 `func`. See Section 6, question 1.

### 2.1 题目

根据以下电子邮件的内容，写一个电邮给对方。

> 发件人：赵世亮
> 收件人：李明华
> 日期：2026年1月28日
> 主题：中学迎新活动
>
> 明华：
> 　　你好！最近还好吗？好久没联络了。
> 　　最近，学校为我们中一新生举办了迎新活动。我们班的同学们认识了几位学长学姐，同学之间也玩得很愉快。
> 　　你学校的迎新会上有什么活动呢？你参加迎新会时有什么感受？希望你能与我分享。
> 　　好了，我就写到这里。希望早日收到你的回邮。
> 　　祝好！
> 世亮

(Email addresses dropped from the student-facing version.)

### 2.2 写作支架（教师材料）

**说好一个活动：** 什么时间、什么人、什么地点、什么事。

| 结构 | 写什么 |
| --- | --- |
| 主题 | 回复：中学迎新活动 |
| 称呼 | 世亮： |
| 问候 + 写作目的 | 问候对方，说明这封电邮要分享迎新会的活动和感受 |
| 分享迎新会活动 | 首先……；其次……；最后…… |
| 分享感受 | 我一开始感到……，因为……；后来，我感到……，因为…… |
| 结束语 | 希望早日收到你的回邮 |
| 祝语、署名 | 祝好！ / 明华 |

### 2.3 范文

The teacher frame gives only the first activity sentence. The rest is **[新拟]**, written to fill the same frame.

> 主题：回复：中学迎新活动
>
> 世亮：
> 　　你好！我最近过得很好，你呢？[[我写这个电邮，是想和你分享我参加中学迎新会的活动和感受。|1]]
> 　　你问我迎新会上有什么活动。[[首先，|2]]我们先到课室参加升旗礼。我们的级任老师与班上的同学进行自我介绍，并且为我们点名，再安排了班上的座位。[[其次，|2]]学长学姐带我们参观校园，告诉我们图书馆、食堂和科学实验室在哪里。[[最后，|2]]我们在礼堂玩团体游戏，每一组都要合作完成任务，大家玩得满头大汗。
> 　　你也问我参加迎新会时有什么感受。[[我一开始感到有些紧张，因为班上的同学我一个也不认识。后来，我感到轻松多了，因为在玩游戏的时候，我和组员一起想办法，很快就成了朋友。|3]]
> 　　好了，我就写到这里。希望早日收到你的回邮。
> 　　祝好！
> 明华

**批注（notes）**
1. 开头说明写作目的，让读者一看就知道这封电邮要写什么。
2. 用“首先、其次、最后”分享三个活动，顺序清楚。
3. 写感受时说出心情的变化（紧张，然后轻松），每一种心情都说明原因。

## 3. G3 实用文：私人电邮《中学生活》（教师材料）

**Proposal:** add as a G3 私人电邮 practice next to the current G3 formal email. See Section 6, question 1.

### 3.1 题目

根据以下电子邮件的内容，写一个电邮给对方。

> 发件人：陈家明
> 收件人：陈松华
> 日期：2026年4月30日
> 主题：中学生活
>
> 松华：
> 　　你好。爸爸好久没给你写电邮了。你和妈妈最近还好吗？
> 　　自从爸爸来到美国工作后，家里的许多事情就靠你和妈妈了。你刚刚升入中学，可能需要一段时间来适应中学生活。
> 　　你选择了什么课程辅助活动？你喜欢吗？你在中学有没有遇到困难呢？
> 　　希望早日收到你的电邮，好让爸爸知道你的近况。
> 　　祝好！
> 爸爸

### 3.2 内容结构（教师材料）

| 结构 | 写什么 |
| --- | --- |
| 问候 + 写作目的 | 您好。我写这封电邮给您，是为了…… |
| 回答问题一 | 我选择的课程辅助活动是……。我喜欢／不喜欢……。首先，……；其次，…… |
| 回答问题二 | 我在中学遇到了一些困难：第一，……；第二，…… |
| 结束语 | 爸爸，以上就是我在中学的生活。希望早日收到您的电邮。 |

### 3.3 范文（教师范文，已修订）

> 主题：回复：中学生活
>
> 爸爸：
> 　　您好！[[我今天写电邮给您，是为了和您分享我的中学生活。|1]]
> 　　我选择的课程辅助活动是羽毛球，我非常喜欢这个活动。[[首先，|2]]这个活动能让我的球技进步。我从小就对打羽毛球很有兴趣，加入学校球队后，有了更专业的训练。在教练的耐心指导下，我的发球和扣杀技术都进步了很多，这让我很有成就感。[[其次，|2]]我在队里认识了很多来自不同班级的新朋友。我们会一起练习，也会互相比赛。遇到困难时，我们会互相鼓励，大家相处得非常愉快。
> 　　我在中学也遇到了一些困难。第一，我跟不上学习进度。上中学后，要学习的科目变多了，地理和历史对我来说都很陌生，数学的内容也越来越深，我感到有点吃力。[[所以，我会在课后请教老师和同学。|3]]第二，我的学校生活非常忙碌。中学的上课时间比较长，下午还要参加课程辅助活动的训练。回到家时我已经很累了，但还要完成功课和复习。[[所以，我制定了时间表，更好地利用时间。|3]]
> 　　爸爸，以上就是我在中学的生活。希望早日收到您的电邮。
> 　　祝好！
> 松华

**批注（notes）**
1. 开门见山说明写作目的。写给长辈，用“您”。
2. 回答问题一：先说喜欢，再用“首先、其次”说明两个原因，每个原因都有具体例子。
3. 回答问题二：说了困难，也说了解决的方法，让爸爸放心。

**Changes from the teacher file:** “目的是为了” changed to “是为了” (redundant); “你” to “您” throughout for a parent; “感到很有成就感” to “很有成就感”; “我会在课后问老师和朋友” to “请教老师和同学”; “所以，我要制定时间表” to “我制定了时间表”; the long CCA paragraph trimmed of one repeated “认识了很多新朋友”.

## 4. G3／HCL 作文：情境记叙文《找到一个好朋友》（教师材料）

**Fit:** matches the roadmap writing skill for G3 and HCL word for word, and the 比喻 and 人物描写 focus.

**Proposal:** add as a second 记叙文 under 作文 for the G3 and HCL doors, with the 审题、选材、列提纲 steps below as its `steps`, and the 范文 in 4.5 as a second model tagged G3. The current model《那一次，我鼓起了勇气》stays as the G2／G3 reference. This needs `model` to become a list, see Section 6, question 2.

### 4.1 题目

升上中学后，你和新同学都不熟悉。经过一件事后，你找到了一个好朋友。写出事情的经过，并加入人物描写。

**学习目标：** 掌握构思三步骤（审题、选材、列提纲）；加入人物描写（外貌、行动、语言、心理）。

### 4.2 第一步：审题（找出关键词，5W1H）

| | |
| --- | --- |
| 时间 | 升上中学后 |
| 地点 | 校内或校外 |
| 人物 | 我，和一个后来成为我朋友的新同学 |
| 事情 | 让我和新同学从不熟悉变成朋友的一件事 |

### 4.3 第二步：选材（这件事适合吗？）

1. 看到我被欺负，国华主动鼓励我、帮助我，让我变得有勇气，敢于说“不”。
2. 我和刚认识的同学一起到东海岸玩。我和小美一起准备食物，彼此也更熟悉了。
3. 休息时我不小心打翻了面碗。我十分狼狈，新同学丽梅主动帮忙，我非常感激她。

（学生判断“适合／不适合”，并说明原因。）

### 4.4 第三步：列提纲（以题材 3 为例）

| 部分 | 写法 | 内容 |
| --- | --- | --- |
| 起因 | 简短 | 我在课间休息时打翻了刚买的一碗面 |
| 经过 | 详细，加入人物描写和细节 | 丽梅怎样帮助我？我有什么反应？心里多么感激她？ |
| 结果 | 简短 | 在丽梅的帮助下，我的麻烦解决了；我也找到了丽梅这个热心助人的朋友 |

**小练笔（教师材料）：** 扩写这个情节：丽梅带我去学校办公室，帮我擦衣服，并帮我向职员借校服。
- 外貌描写：丽梅有怎样的外貌？她看到我狼狈的样子，脸上是什么表情？
- 行动描写：丽梅是怎么帮助我的？
- 语言描写：丽梅跟我说了什么？语气是怎样的？

### 4.5 范文（教师范文，已修订）

> 　　时间过得很快，今年我升上了中学。刚开学时，我不熟悉新学校的环境，上学时很紧张。我很害羞，不敢和新同学开口说话。有的同学还因为我沉默寡言，以为我很骄傲。还好，后来发生了一件事，终于让我交到了一个好朋友。
> 　　记得有一天休息的时候，我买了一碗云吞面。在走回座位时，我一不小心踩到地上的一滩水，“砰”的一声，重重地摔在地上。[[回过神来，面汤已经洒了我一身，原本整齐的校服变得湿漉漉的，非常狼狈。|1]]热闹的食堂顿时安静下来，所有人的目光都集中在我身上，有些人还哈哈大笑起来。[[我躺在那里，手足无措，快要哭了。|2]]
> 　　这时，在一片笑声和耳语中，我听到了一个声音：“你还好吗？有没有哪里受伤？”我抬起头，看到一张熟悉的面孔，原来是同班的明华。[[明华蹲在我身边，从口袋里拿出纸巾，为我清理校服上的面条。擦完后，他小心翼翼地扶我起来，搀扶着一拐一拐的我走向办公室。|3]]
> 　　到了办公室，[[他亲切地对我说：“你先坐在这里，我去问老师有没有多余的校服可以借你。”|4]]我坐在那里，心想：明华为什么要帮我呢？他的衣服也被我弄脏了。不久，明华拿着一套干净的校服走出来，让我到厕所换上。
> 　　因为这件事，我开始和明华一起吃饭、聊天，慢慢地成了好朋友。[[我很感谢他没有和其他同学一起嘲笑我，而是勇敢地上前帮我。有了明华，我的中学生活不再孤单，交朋友也越来越有自信。|5]]

**批注（notes）**
1. 细节描写：写出校服和面汤，让读者看到“我”有多狼狈。
2. 心理描写：用“手足无措，快要哭了”写出当时的无助。
3. 行动描写：“蹲、拿出、清理、扶、搀扶”一连串动作，写出明华的细心。
4. 语言描写：明华说的话亲切、具体，表现他热心助人。
5. 结尾：总结事情的影响，并写出感想，和开头的“害羞、不敢说话”前后呼应。

**Changes from the teacher file:** “那里受伤” to “哪里受伤”; mismatched quotation mark fixed; “同学—— 明华” to “同学明华” (no dash); “我很感谢因为他没有” to “我很感谢他没有”; “额外的校服” to “多余的校服”; “害羞、害怕” to “害羞” (repetition); last sentence “我真庆幸在中学找到了明华这个见义勇为，挺身而出的好朋友！” dropped, because 见义勇为 is too strong for helping after a fall. Restore it if preferred. Paragraph headings (开头、主体、结尾) moved out of the text.

**Gap for HCL:** the roadmap adds 比喻 and 夸张 and “从不同方面分析人物形象”. The 范文 has no 比喻 yet. Suggested **[新拟]** addition after note 1: 那一刻，我觉得自己像一只被雨淋湿的小狗，只想找个地洞钻进去。
