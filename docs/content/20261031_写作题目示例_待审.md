## 网络贴文：参观新加坡动物园

`ex-g1-zoo-post` · 实用文题目示例 · s2u2 关爱动物 · G1

**题目：** 写一个贴文，和朋友分享你去参观新加坡动物园的事。描写时，要举例说明动物园里有些什么动物，并写出至少其中一种动物的特点。（60字以上）

**拆解题目**

| | |
| --- | --- |
| 文体 | 网络贴文，写给朋友看 |
| 写什么 | 一次参观新加坡动物园的经历 |
| 任务一 | 举例说出动物园里有哪些动物 |
| 任务二 | 写出至少一种动物的特点 |

**针对题目作答**

1. 开头：和朋友打招呼，说出什么时候、和谁去了动物园。
2. 中间：说出看到的两三种动物。
3. 再选一种动物，写它的外形、动作或叫声。
4. 结尾：写出自己的心情。

**可以写的内容**

- 看到的动物：长颈鹿、大象、红毛猩猩、白老虎……
- 动物的特点：长颈鹿的脖子长长的；红毛猩猩在树上荡来荡去……
- 心情：开心、兴奋、难忘

**常见失误**

- 只写了动物的名字，没有写出任何一种动物的特点。
- 写成一篇作文，忘了贴文要和朋友分享的语气。

## 网络贴文：回应同学的运动会贴文

`ex-g1-sports-day-post` · 实用文题目示例 · s3u2 健康生活 · G1

> 方志强
> 精彩的运动会
>
> 大家好！
> 最近，我的学校举办了一年一度的运动会，运动会上有很多不同的比赛项目。
> 你的学校有没有举办过运动会呢？你对哪些运动最感兴趣？

**题目：** 假设你是伟明，请根据网络贴文的内容，写出你的回应。（75字以上）

**拆解题目**

| | |
| --- | --- |
| 文体 | 回应网络贴文 |
| 身份 | 你是伟明，回应志强 |
| 问题一 | 你的学校有没有举办过运动会？有哪些项目？ |
| 问题二 | 你对哪些运动最感兴趣？为什么？ |

**针对题目作答**

1. 先直接回答：我的学校有（或没有）举办过运动会。
2. 说出两三个比赛项目，例如长跑、短跑、接力赛。
3. 说出你最感兴趣的运动，再写两三个原因。

**可以写的内容**

- 比赛项目：长跑、短跑、接力赛、跳远
- 感兴趣的原因：适合自己、可以锻炼身体、让自己更健康、可以和朋友一起参加

**常见失误**

- 只说出感兴趣的运动，没有说原因。
- 两个问题只回答了一个。

**参考回应**

> 志强，你好！我的学校每年都会举办运动会，比赛项目有长跑、短跑和接力赛。我对长跑最感兴趣，因为我的腿很长，很适合长跑。长跑可以锻炼身体，长期跑步也能让我更健康。

- 一个要点只写一句话，没有原因或例子。

> 要让同学们正确使用回收箱，我有以下建议：第一，礼貌地提醒同学。如果看到同学把垃圾放错地方，你可以告诉他们哪些物品可以回收，哪些不能回收。这样他们以后就知道怎样正确使用回收箱，也能减少放错垃圾的情况。

1. 先表明立场，再用“会……，这样……”说明影响。
2. 建议的写法：先说建议，再说怎么做，最后说有什么效果。

| --- | --- |
| 文体 | 私人电邮（回复朋友） |
| 身份 | 你是丽华，回复伟明 |
| 问题一 | 他这样做到底对不对？（立场加至少两个原因） |
| 问题二 | 他该怎么做才能挽回这段友谊？（至少两个建议） |

**针对题目作答**

1. 第一段：问候，再用一句话说明写电邮的目的，目的要提到对方问的事情。
2. 中间段落：一个问题写一段，按对方提问的顺序回答。
3. 每一段先用一句话直接回答，再说明原因或举出具体例子。
4. 最后一段：结束语，回应对方，期待回复。

**可以写的内容**

- 可以选的立场：对；错；出发点正确，但做法错了（没有先私下劝朋友）。
- “对”的原因：朋友的情况已经需要大人帮忙；家长更有经验；及早反映可以防止情况恶化；出发点是关心。
- “错”的原因：违背了保守秘密的承诺；没有先问朋友的意思；朋友会觉得被出卖，信任受损。
- 挽回友谊：真诚道歉，不为自己辩解；简短说明是因为担心他；尊重他的情绪，给他时间；以后守信用，用行动重建信任；隔一段时间再关心他。

**常见失误**

- 目的放在第二段，或只写“我写电邮是为了回答你的问题”，没有说出具体的事。
- 只回答了一个问题，漏掉另一个。
- 一个要点只写一句话，没有原因或例子。
- 格式不完整：主题、称呼、祝语、署名缺一不可，“回复”的主题和双方身份不能写反。
- 同时说“对”又说“错”，立场互相矛盾。
- 去评价伟强的对错，而不是回答伟明的问题。
- 建议请老师或别的朋友出面调解：让更多人知道，朋友可能更生气。

## 公务电邮：组屋区里不负责任的宠物主人

`ex-g2-pet-owners` · 实用文题目示例 · s2u2 关爱动物 · G2

**题目：** 最近，你发现住家附近的组屋楼下，常有居民遛狗时不牵好绳子，让宠物随处大小便，事后也不清理。这不但影响了邻里的卫生，也给其他居民带来了不少困扰。<br>假设你是本区居民陈家伟，试写一封电邮给市镇理事会的林经理，向他说明这些居民的行为给你和其他邻居带来的影响，并针对解决问题的方法提出建议。

**拆解题目**

| | |
| --- | --- |
| 文体 | 公务电邮 |
| 身份 | 本区居民陈家伟 |
| 写给谁 | 市镇理事会林经理 |
| 任务一 | 说明这些行为带来的影响（至少两点） |
| 任务二 | 提出解决问题的建议（至少两点） |

**针对题目作答**

1. 第一段：问候，说明自己的身份，再说明写电邮的目的。
2. 第二段：反映情况，说清楚发生了什么、带来什么影响，不要照抄题目。
3. 第三段：提出至少两个具体建议，每个建议说明怎么做、为什么有用。
4. 最后一段：客气话、结束语和致谢，署名写上题目给你的身份。

**可以写的内容**

- 影响：粪便无人清理，环境脏、有异味、招蚊虫；不牵绳的狗可能吓到或咬伤老人和小孩；居民互相投诉，邻里不和；影响组屋区的形象。
- 建议：在楼下贴告示，提醒遛狗要牵绳、自备清洁袋；增设宠物粪便箱和免费清洁袋；派人不定时巡查，屡劝不改的给予警告或罚款；通过居委会和邻里群组宣导，做负责任的宠物主人。

**常见失误**

4. 结论：重申立场，总结分论点，提出呼吁或建议。

**可以写的内容**

- 同意（要靠自律）：饮食习惯根深蒂固，要靠内在动力才能持久；个人缺乏意识，健康餐也达不到效果。
- 反对（政策不可或缺）：慢性病问题严峻，需要系统的推动；好的饮食环境降低做出正确选择的门槛；政策和自律相辅相成。

**常见失误**

- 两个板块只讨论了一个。
- 只列出正反意见，没有表明立场。
- 只谈健康饮食的好处。
